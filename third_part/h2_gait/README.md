# h2_gait —— H2 腿部小碎步控制

步态相关代码统一放这个文件夹。目标：让 H2 在运动模式下用**腿**做小步平移
（前后 / 左右各几厘米），用于拨闸前的基座微调。不碰腰、不碰手臂。

## 文件

| 文件 | 作用 |
| --- | --- |
| `server.py` | **独立控制服务**（FastAPI，端口 9210）：按住/点动两种模式，里程计闭环，不启动任何相机服务 |
| `web/index.html` | 控制页面：按住控制（死人开关心跳）+ 点动控制（单击一步） |
| `shuffle.py` | 小碎步控制器 `H2Shuffle` + 命令行点动工具（开环版，服务不依赖它的控制逻辑） |
| `query_fsm.py` | 只读查询运控状态（不发运动指令），用来确认遥控器模式 ↔ FSM id 的对应关系 |
| `logs/` | 点动记录 jsonl（自动生成），供标定"指令位移 vs 实际位移" |

## 快速开始（真机）

```bash
# 网页控制（推荐）：起服务后浏览器开 http://<本机IP>:9210/
python3 third_part/h2_gait/server.py --iface enp86s0 --port 9210

# 只读查状态：遥控器切模式前后各跑一次，对比 fsm_id
python3 third_part/h2_gait/query_fsm.py enp86s0

# 命令行点动（开环备用）
python3 third_part/h2_gait/shuffle.py enp86s0
> l 5      # 左移约 5cm
> s        # 急停
```

### 网页控制说明

- **按住控制**：按住方向键持续移动，松开即停。前端 0.3s 心跳一次，后端每次
  发 0.8s 速度脉冲互相覆盖；心跳断流 0.9s 内看门狗显式刹车（死人开关）。
  键盘 W/S/A/D 平移、Q/E 旋转。
- **点动控制**：单击走一步（默认 3cm）。**里程计闭环**：订阅
  `rt/odommodestate`（H2 实测 500Hz），实测挪够设定距离立刻刹车，
  页面显示指令 vs 实测位移。里程计无数据时自动退化为开环时长。
  **自动升速**：平移有迈步阈值（真机实测 0.12 m/s 只会倾斜重心不挪脚），
  点动从低档起，每 1s 检查进展，<1cm 就升档
  （前后 0.12→0.18→0.25，横移 0.15→0.22→0.28 m/s），升到顶仍不走则超时报错。
- 两种模式互斥；红色急停按钮常驻右下角。
- 速度限幅：前后 ≤0.35、横移 ≤0.30 m/s、旋转 ≤34°/s；单步 ≤15cm。

代码里调用：

```python
from third_part.h2_gait import H2Shuffle

sh = H2Shuffle().connect("enp86s0")   # 或 .attach(已有的 LocoClient)
sh.step(dy_cm=+5)                      # 左移约 5cm
```

## 原理与真机结论

走高层 `LocoClient.SetVelocity(vx, vy, 0, duration)`：本体运控自己迈步、
自己平衡，我们只给方向和量。这与对中转身（只给 omega）是同一条通道，
已在真机验证可用、且与 `rt/arm_sdk` 手臂控制共存。

本机（2026-07-31 实测 `GetAvailableFsmIds`）的行走类 FSM：

| fsm_id | 名称 | 说明 |
| --- | --- | --- |
| 601 | HybridWalk | 行走策略 |
| 701 | WalkNew | 行走策略 |
| 703 | PhaseWalk | 行走策略。**遥控器"运动2"实测就是它**（2026-07-31，切换后 GetFsmId=703、fsm_mode=1） |
| 4 | FixStand | 锁定站立（**不受理速度指令**） |
| 1 / 0 | Passive / Invalid | 阻尼 / 无效 |

其余遥控器模式对应哪个 fsm_id，用 `query_fsm.py` 切换前后各查一次即可
确认。`step()` 会先校验 FSM 在行走状态，不在就拒发。

## 已知坑（都吸收进 `shuffle.py` 了）

1. **duration 不可靠**：对中曾下发 0.635s（预计 5°）实际转了 ~14°。
   所以每杆脉冲结束都显式 `StopMove()` 刹车，不指望固件按时长自停。
2. **RPC 3104 = 应答超时**，指令多半已执行，不能当失败重发。
3. **小速度死区**：速度太小策略可能原地踏步不位移，默认用 0.08 m/s
   的"稍快短脉冲"。
4. **开环误差大**（±50% 量级）：单杆只保证"朝对的方向挪一小步"，
   精确到位靠外部反馈（视觉/里程）多杆逼近，和对中的收敛套路一致。
5. 迈步是全身动作，会带动前伸的手臂——**先收手再走步**。
